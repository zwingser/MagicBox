# MagicBox 当前产品说明

## 1. 产品定位

MagicBox 是一个以“个人收藏桌面”为核心的多端应用。

它不是传统浏览器书签页，也不是搜索工具，而是一个更像手机主屏的收藏容器：用户把自己常用的网站、网页应用、App Deep Link、小程序链接整理成图标，放在两个主桌面和文件夹中，按自己的习惯排布与打开。

当前版本以 Android 运行体验为主设计目标，同时保留 iOS 和微信多端框架下的兼容结构。

## 2. 目标用户

- 个人重度收藏用户
- 需要集中访问多个站点、网页工具和应用跳转入口的用户
- 希望自己定义布局、而不是依赖平台推荐排序的用户
- 有少量协作分享需求，但当前版本仍以本地个人数据为主

## 3. 核心价值

- 一个入口管理多种链接类型
- 以图标桌面的方式代替线性列表
- 常用内容可被快速触达
- 收藏结构可手动维护、迁移、导入导出
- 固定页提供一个“常驻查看位”

## 4. 当前版本核心能力

### 4.1 收藏对象统一模型

当前系统统一维护以下对象：

- `item`：单个收藏项
- `folder`：文件夹
- `desktop`：桌面页，当前为 `home1` 与 `home2`
- `history`：打开记录
- `settings`：主题、桌面命名、固定页地址等配置

### 4.2 支持的链接类型

- `web`：普通网页或网页应用
- `app`：App Deep Link / Scheme
- `miniProgram`：小程序跳转信息

### 4.3 桌面管理

- 两个主页桌面：`Home 1`、`Home 2`
- 支持图标拖拽排序
- 支持拖入已有文件夹
- 支持图标覆盖图标后创建新文件夹
- 支持跨桌面移动

### 4.4 快速添加与编辑

- 中央 `+` 按钮打开浮层
- 同一个浮层同时承担“新增”和“编辑”两种模式
- 可自动识别链接类型
- 可设置标题、目标桌面、文件夹归属、颜色、备注

### 4.5 固定页

- 固定页只接受 `http(s)` 地址
- 地址由设置页统一配置
- 作为一个固定访问位存在
- 未配置时展示空状态，并直接引导到设置页配置

### 4.6 数据管理

- 本地存储
- JSON 导入 / 导出
- 一键重置为种子数据

## 5. 数据模型摘要

### item

- `id`
- `title`
- `type`
- `url`
- `appId`
- `path`
- `badge`
- `color`
- `desktop`
- `folderId`
- `note`
- `createdAt`
- `updatedAt`
- `lastOpenedAt`

### folder

- `id`
- `title`
- `badge`
- `color`
- `desktop`
- `itemIds`
- `createdAt`
- `updatedAt`

### settings

- `theme`
- `pageNames.home1`
- `pageNames.home2`
- `fixedPageUrl`

## 6. 关键产品语义

### Home 1

- 主桌面一
- 顶部展示最近 5 次打开记录的轮播 Banner
- 下方为可操作图标网格

### Home 2

- 主桌面二
- 不显示 Banner
- 直接展示图标网格

### Fixed Page

- 不是历史页
- 不是搜索页
- 是一个单独的固定内容入口

### Add

- 不是主页面
- 是由 Dock 中央圆形按钮触发的浮层能力

## 7. 当前不做的内容

- 云同步
- 多人实时共享
- 自动抓取网页 favicon 与站点截图
- 微信个人小程序内的任意外站稳定直开承诺
- 搜索型首页

## 8. 产品方向结论

MagicBox 当前版本已经从“多端万能入口探索”收束到“Android 优先的个人收藏桌面工具”。

它的设计重心不再是解释功能，而是让用户像摆放手机图标一样维护自己的入口系统。
