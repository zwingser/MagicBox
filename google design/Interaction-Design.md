# MagicBox 交互设计

## 1. 总体交互原则

- 以手机桌面式交互为参考
- 以“直接操作”优先于“列表配置”
- 常用操作保持低层级
- 编辑不打断主导航结构
- 不增加不必要的搜索和说明层

## 2. Dock 交互

### 2.1 结构

Dock 包含 4 个主图标和 1 个中央操作按钮：

- 左侧：`Home 1`
- 左侧：`Home 2`
- 中央：`+`
- 右侧：`Fixed Page`
- 右侧：`Settings`

### 2.2 行为

- 点击 `Home 1 / Home 2 / Fixed Page / Settings`：切换主页面
- 点击 `+`：打开添加浮层
- `+` 不参与左右页面手势切换

### 2.3 视觉意图

- 中央 `+` 明显区别于其他 tab 图标
- 使用更强的按钮感和圆形轮廓
- 表达“创建动作”，而不是“页面切换”

## 3. Home 1 / Home 2 交互

### 3.1 页面分工

- `Home 1`：包含最近打开轮播和图标桌面
- `Home 2`：仅保留图标桌面，结构更纯粹

### 3.2 图标点击

- 点击普通收藏项：按类型打开目标
- 点击文件夹：进入文件夹页

### 3.3 长按与拖拽

长按图标后进入拖拽准备状态，继续移动则进入拖拽。

支持以下行为：

- 拖动到空位：调整顺序
- 拖动到文件夹：移入文件夹
- 在另一个图标上停留：创建新文件夹

### 3.4 文件夹创建

触发条件：

- 来源对象必须是普通 item
- 目标对象必须是普通 item
- 停留足够时长后合并

结果：

- 新建一个 folder
- 新文件夹包含来源 item 和目标 item
- 文件夹放在目标原位置附近

### 3.5 桌面切换

当前主桌面支持手势切换：

- `Home 1` 左滑到 `Home 2`
- `Home 2` 右滑回 `Home 1`

这类切换属于主桌面切换，不包括中央添加浮层，也不包括 Fixed Page。

## 4. Recent Banner 交互

仅 `Home 1` 显示。

### 4.1 展示内容

- 最近 5 次打开记录
- 支持轮播
- 支持手动滑动切换

### 4.2 点击行为

- 点击当前卡片，直接重新打开该记录对应目标

## 5. Add / Edit 浮层

### 5.1 统一入口

添加和编辑复用同一个浮层，而不是拆成两套表单。

新增模式：

- 由 Dock 中央 `+` 打开

编辑模式：

- 由图标长按菜单中的 `Edit` 进入

### 5.2 表单字段

- 标题
- 链接 / Deep Link
- 类型
- 桌面归属
- 文件夹归属
- 颜色
- 备注

### 5.3 智能识别

输入链接后自动推断：

- `web`
- `app`
- `miniProgram`

用户也可以手动覆盖类型。

### 5.4 编辑约束

- 编辑已有项时，应保留原有位置关系
- 修改内容不应把图标自动挪到列表末尾

## 6. 长按菜单

当前桌面上的图标长按菜单统一收敛为：

- `Edit`
- `Delete`

文件夹内部的 item 长按菜单补充：

- `Remove from folder`
- `Delete`

## 7. Fixed Page 交互

### 7.1 语义

Fixed Page 是单一固定网页位，不是历史页，也不是搜索页。

### 7.2 配置规则

- 只接受 `http(s)` 链接
- 地址在设置页配置

### 7.3 未配置状态

- 显示空白占位说明
- 提供“去设置页配置”的动作

### 7.4 已配置状态

- 点击进入应用内部浏览页打开目标
- 优先维持“在 MagicBox 内部查看”的体验

### 7.5 退路策略

如果宿主限制导致 Dock 无法和网页内容同层共存，则至少保证用户仍可返回主桌面，不能形成“进入后出不来”的死路。

## 8. 文件夹页交互

- 点击内部图标：直接打开目标
- 长按内部图标：允许移出文件夹或删除
- 文件夹标题允许修改
- 返回动作保持简单，不额外增加页面选择器

## 9. 设置页交互

设置页承担“低频但必要”的操作：

- 主题切换
- 桌面命名
- 固定页地址维护
- 导入导出
- 重置

设置页不是日常操作主场，因此布局以清晰、稳定、可回访为主。
