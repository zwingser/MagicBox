# MagicBox 页面规格

## 1. Home 1

### 1.1 页面职责

- 展示主桌面一
- 展示最近打开轮播
- 提供图标管理主入口

### 1.2 页面结构

- 顶部安全区留白
- Banner 区
- 图标网格区
- 底部自定义 Dock

### 1.3 关键状态

- 有最近记录
- 无最近记录
- 有图标
- 空桌面
- 拖拽中

### 1.4 关键行为

- 点击 Banner 卡片重新打开
- 点击图标打开
- 长按拖拽
- 滑动切到 Home 2

## 2. Home 2

### 2.1 页面职责

- 展示主桌面二
- 提供更纯净的图标页

### 2.2 页面结构

- 顶部安全区留白
- 图标网格区
- 底部自定义 Dock

### 2.3 与 Home 1 的差异

- 不显示 Banner
- 顶部对齐高度与 Home 1 视觉上保持一致

### 2.4 关键行为

- 点击图标打开
- 长按拖拽
- 滑动切回 Home 1

## 3. Fixed Page

### 3.1 页面职责

- 承接固定网址入口
- 未配置时提供空状态引导

### 3.2 已配置状态

展示：

- 固定页标题
- 当前 host
- 当前完整 URL
- 打开按钮
- 返回 Home 1 的兜底动作

行为：

- 进入 Browser 页面以内嵌方式打开目标

### 3.3 未配置状态

展示：

- “未配置固定页”说明
- 前往设置页按钮
- 返回 Home 1 按钮

## 4. Browser

### 4.1 页面职责

- 承载网页内容打开
- 同时服务普通网页打开与 Fixed Page 打开

### 4.2 模式

- 普通浏览模式
- Fixed Page 模式

### 4.3 关键行为

- 可内嵌预览时优先内嵌
- 必要时允许外部打开或复制链接

### 4.4 设计注意点

- 该页承载的是内容，不应抢走主应用语义
- 如果宿主限制导致固定 Dock 不能稳定显示，需要至少保证可回退路径

## 5. Folder

### 5.1 页面职责

- 展示单个文件夹内的收藏项
- 支持文件夹级管理

### 5.2 页面结构

- 顶部返回
- 文件夹标题与桌面归属信息
- 重命名输入
- 文件夹内图标网格

### 5.3 行为

- 点击图标打开
- 长按图标可移出文件夹
- 长按图标可删除
- 文件夹本身可重命名

## 6. Settings

### 6.1 页面职责

- 统一维护全局配置

### 6.2 页面模块

- Theme
- Page Names
- Fixed Page URL
- Export
- Import
- Reset

### 6.3 Fixed Page 配置模块

输入限制：

- 只接收 `http(s)` 地址

交互结果：

- 保存成功后更新固定页配置
- 清空后 Fixed Page 回到未配置状态

## 7. Add / Edit Sheet

### 7.1 页面职责

- 统一处理新增与编辑

### 7.2 结构

- 标题区
- 链接输入
- 类型选择
- 桌面选择
- 文件夹选择
- 颜色选择
- 备注
- 保存按钮
- 新建文件夹区域

### 7.3 特点

- 中央弹出
- 不离开当前主页面上下文
- 编辑和新增使用同一套界面模型
